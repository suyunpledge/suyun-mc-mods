# BladeCombo — 拔刀连斩

**固定连招的拔刀剑** Fabric 模组（MC **1.20.1**，需要 Fabric Loader **0.16.10+** 与 Fabric API）。为手残党设计：
只要按着连招操作点下去，就是无限斩击。

## 连招系统

### ⚔️ 无限四段连招（连点攻击键）

| 段 | 招式 | 倍率 | 特效 |
| --- | --- | --- | --- |
| 一 | 一之太刀·横斩 | ×1.0 | 突进斩击 |
| 二 | 二之太刀·逆袈裟 | ×1.2 | **挑空**目标 |
| 三 | 三之太刀·回旋斩 | ×1.5 | **360° 范围**横扫（半径 2.5 格） |
| 四 | 奥义·幻影连斩 | ×2.0 | 爆炸演出 + **大击退** |

- **无限循环**：第四段后接第一段，只要在连招窗口（默认 0.75 秒，可配置）内继续攻击，
  1234→1234→……永远连下去；动作栏实时显示「连击 N —— 招式名」
- **手残党核心机制：每次斩击命中即重置攻击蓄力**（`resetAttackStrengthTicker`）——
  原版连点会被 0.5 秒攻击冷却惩罚，拔刀剑不会，**怎么点都是满蓄力伤害**
- 每斩小幅**突进**（第四段突进更长），贴身缠斗手感
- **点击缓冲**：攻击间隔内的最后一次有效点击会自动补发；换刀、目标死亡、离开攻击范围或视线被挡时不会补刀
- **分段动画**：第一/第三人称均有横斩、上挑、回旋与交叉终斩动作，左右手自动镜像；附近玩家也能看到同步刀光
- **平滑刀光**：带状弧光按帧插值并渐隐，不再只有原版挥手和粒子；格挡时显示护弧，弹刀时短促增亮

### 🛡️ 连招格挡（右键）

- **触发条件（特定连招操作）**：命中后 **0.6 秒内**右键，或**潜行**右键
- **完美格挡**：命中后 **4 tick（0.2 秒）内**衔接 → **无冷却**，可以斩一格挡一循环
- 效果（1.5 秒架势）：受到伤害 **-90%**、**弹刀**（近身攻击者受 30% 反伤 + 击退 + 迟缓 II）
- 普通衔接有 3 秒冷却；条件不满足会提示原因

### 🌙 空中连招·软着陆

- **滞空状态下的每次斩击**刷新 4 秒"空中连段"状态
- 期间 `fallDistance` 持续归零，**摔落伤害完全免疫**（着地时"软着陆"提示 + 尘土粒子）
- 跳劈、下落追击、从高处连怪落地——全部无伤

## 四阶拔刀（合成升阶）

```
竹 光      = 竹×2 竖排 + 铁锭（柄）
铁刃·疾风  = 竹光 + 铁锭×4（十字包裹）
钻石刃·晓  = 铁刃 + 钻石×4（十字包裹）
合金刃·终焉 = 钻石刃 + 下界合金锭×4（十字包裹）
```

耐久 512/1024/2048/3072，攻击加成 +3/+5/+6/+8，全部进入创造物品栏"战斗"页。
**击杀数记录在物品 NBT**，tooltip 显示「击杀数：N」——养一把自己的刀。

## 构建与安装

```bash
./gradlew build          # Windows: gradlew.bat build
# 产物: build/libs/bladecombo-1.1.0.jar
```

## 配置（`.minecraft/config/bladecombo.json`）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `comboWindowTicks` | `15` | 连招衔接窗口（15=0.75 秒） |
| `swingIntervalTicks` | `6` | 两次斩击最小间隔 |
| `parryDurationTicks` | `30` | 格挡架势持续 |
| `parryCooldownTicks` | `60` | 格挡冷却（完美格挡不受此限） |
| `parryDamageFactor` | `0.10` | 格挡时受伤比例 |
| `parryReflectFactor` | `0.30` | 弹刀反伤比例 |
| `airComboTicks` | `80` | 空中连段（免摔落）持续 |

## 实现

- `AttackEntityCallback` 拦截拔刀攻击，服务端连招状态机保留单次点击缓冲，并在补发前复查目标
- 命中调用 `resetAttackStrengthTicker()`，自定义倍率不受原版连点蓄力惩罚
- `ALLOW_DAMAGE` 负责格挡减伤/弹刀和空中连段免疫；弹刀递归保护使用 `try/finally`
- 服务端只在实际斩击、格挡和弹刀时发送事件，客户端保存短时动画状态，不逐 tick 发网络包
- 两个客户端专用 Mixin 叠加第一/第三人称持剑动作；世界渲染事件绘制透明带状刀光，服务端不加载渲染类
- 动画结束、换世界和断线会清理客户端状态

```
src/main/java/com/bladecombo/

```
