# Herobrine（HIM）都市传说考察报告

> 本文档是模组 **HIM — The Haunting of Herobrine** 的资料基础。
> 调研日期：2026-10-24。来源：Wikipedia《Herobrine》词条、Minecraft Wiki《Herobrine》词条、
> KnowYourMeme、Minecraft@Home 项目相关报道等（文末附链接）。

---

## 1. 起源：2010 年 8 月的 4chan 帖子

- **时间**：2010 年 8 月 30/31 日前后（多数资料指向 8 月 31 日）。
- **地点**：4chan 的 `/x/`（超自然板，亦有说法最初发于 `/v/`，原帖本体至今仍是"遗失媒体"，
  r/lostmedia 上仍有追踪原帖的讨论）。
- **核心情节**（据 Wikipedia / Minecraft Wiki 转述）：
  1. 发帖人在**单人模式**生存世界里，透过浓雾看见远处有个"像牛一样的身影"；
     靠近后发现那是一个**双眼纯白（没有瞳孔）的玩家形象**，正站在雾中盯着他，
     随即消失。
  2. 此后他的世界里开始出现**他自己从未建造过的结构**。
  3. 他在论坛发帖询问，**帖子被删除**；最终他收到一个用户名为 **"Herobrine"** 的私信，
     内容只有一个词：**"Stop"**。
  4. 帖中引述传闻：Herobrine 是 Notch 的兄弟的游戏 ID。发帖人邮件询问 Notch 是否有兄弟，
     得到的回复是：**"I did, but he is no longer with us."**（有过，但他已经不在了。）
     —— 事后证实这是都市传说自我编排的部分，**Notch 实际上从未有过兄弟**。
- **同期关联传说**："White Eyes（白眼）"——听过唱片 **13 号唱片**后，在洞穴中目击的白眼实体，
  被社区并流为 Herobrine 的早期变体。

## 2. 病毒式传播：两场"被目击"的直播

### 2.1 Copeland 的 Brocraft 直播（2010 年 10 月前后）

- 主播 **Copeland** 看到原始帖后非常喜欢，决定"安排一次遭遇"：
  - 他准备了一个**自定义纹理包**：把游戏内某种方块（广为流传的说法是**门的贴图**，
    亦有"苔石"之说）替换成 Herobrine 的脸（Steve 的脸 + 纯白双眼）。
  - 直播约 **2 小时**的生存建房过程；随后进入一个**未装修的空房间**，
    Herobrine 正站在里面盯着他 —— Copeland 假装惊慌逃离并**立刻切断直播**。
  - 事后宣称"再次尝试直播时电脑崩溃"，并把观众引导到一个名为 **`him.html`** 的网页：
    页面是一张 Herobrine 的 GIF（双眼会转动），配文大意为
    *"You are living in a fantasy world inside your mind ... WAKE UP"*。
    —— **Herobrine 的绰号 "HIM" 即来自 `him.html`。**
- 事后 Copeland 承认造假：一切由**纹理替换**实现，这就是中文社区所称"恐怖分子 Herobrine"
  最经典的形象来源。

### 2.2 Patimuss 的直播

- 另一位主播 **Patimuss** 有样学样：直播中"发现" **Herobrine 在岩浆上行走**，
  随即以受惊为由退出游戏。
- 同样事后被揭穿（重制纹理/宏）。两场直播共同把 Herobrine 从一个 4chan 帖子
  推成了 Minecraft 社区的顶级都市传说。

## 3. 社区共识：Herobrine 的行为特征

| 特征 | 描述 |
| --- | --- |
| 外形 | 与 Steve 相同的玩家模型，**双眼纯白发亮、无瞳孔** |
| 出现位置 | **浓雾边缘 / 视野尽头 / 远山 / 密林**，距离感极强 |
| 行为 | **静静站着盯着玩家**；从不说话；**从不主动攻击** |
| 消失方式 | 被接近、被注视即消失；有时"一转头就不在了" |
| 破坏性 | 间接的：世界被"动过"的痕迹，而非当面破坏 |
| 召唤 | 社区流传的金块图腾仪式（见 §5） |

## 4. 经典"证据"结构与世界异象

以下结构在 2010–2012 年的"目击截图"中反复出现，是传说的标志性元素：

1. **水中/海面的沙金字塔** —— 小型、棱角完美的沙堆金字塔出现在海中。
2. **被扒光树叶的树** —— 整片森林的树只剩光秃秃的原木。
3. **山体上的 2x2 隧道** —— 笔直切入山体、带拐角，内壁完美；**隧道里插着红石火把**。
4. **下界岩之火** —— 地表凭空出现燃烧着永恒之火的下界岩。
5. **诡异告示牌** —— 著名伪造截图中的字句，如 **"ONLY GOD CAN HELP YOU NOW"**。
6. **火把异变 / 迷雾 / 诡异音效**（洞穴音效、13 号唱片）与"被删除的帖子"叙事。

## 5. 召唤图腾（社区仪式，模组已还原）

最流行的版本（The Legend of Herobrine 等经典模组采用）：

```
        [下界岩 Netherrack]     ← 用打火石点燃（永恒之火）
     [红石火把 x4 贴于上层金块四侧]
        [金块 Gold Block]
        [金块 Gold Block]
```

变体包括 3x3 金块环 + 苔石中央的"祭坛"（护城河式：9 金块 + 12 红石火把）等。

## 6. 官方态度与彩蛋

- **"Removed Herobrine"**：自 **Beta 1.6.6（2011-05-31）** 起，Java 版几乎每个正式版的
  更新日志都包含玩笑条目 **"Removed Herobrine"** —— Minecraft Wiki 统计其出现于
  从 Beta 1.6.6 到 1.21.x 的历代更新说明中；愚人节版本 **20w14infinite** 的更新日志里
  更是一连写了 **15 遍** "Removed Herobrine"。
- **Notch**：多次公开否认（2011 年在 Twitter 表示从未有过兄弟），
  同时又乐于玩梗，从未彻底"杀死"这个传说。
- **Jeb（Jens Bergensten）** 接受采访时表示：
  *"We don't usually talk about Herobrine... It's a mystery... And we don't quite confirm if it's true or false."*
- **Warden（监守者）**：总监 Agnes Larsson 承认监守者的恐怖设计参考了社区恐怖"传说"。
- **《我的世界大电影》（2025）**：Steve（Jack Black 饰）在末影人幻觉场景中一度**双眼发出白光**，
  被广泛解读为 Herobrine 致敬；官方解释为"赶工遗留的 VFX 瑕疵"。

## 7. 考古与延续

- **2020 年**：玩家 Enderboss25 联络到 Copeland 本人，原始录像已丢失，
  但**世界存档被找回**，二人合作复刻了当年的直播。
- **2021 年**：Minecraft@Home 项目（负责人**安田·"Andir"**？——团队协作）找到了
  原始目击截图的世界种子：**`478868574082066804`**（Java Alpha 1.0.16_02）。
- **2024 年 7 月**：用户 brutallillfjomp 上传了自己 2010 年不知情录下的
  原始直播视频，"遗失媒体"意外回归。
- Herobrine 曾在 2013 年吉尼斯"游戏反派 Top 50"投票中名列第 46 ——
  **作为一个并不存在的角色**。

## 8. 实体 303（Entity 303）与"双雄之战"

### 8.0 其余传说成员（v1.2 新增）

- **白眼（White Eyes）**：2010 年 7 月 30-31 日，Herobrine 传说的直接前身。
  用户 Flaky 在 Minecraft Forum 转述 4chan /v/ 帖：听过**13 号唱片**后，
  洞穴中出现"一双发着白光的眼睛"，远远注视玩家（Endorphine 后续帖描述其为雌性生物，
  只在远处观察，从不靠近）。该传说被认为源自早期图形 bug（远处方块接缝处的白色像素）。
  —— 模组还原：只在黑暗中现身、火把照亮即消失、13 号唱片联动增益。
- **实体 Null**：约 2012-2013 年兴起：全黑人形、沉默，与"存档损坏/方块被替换"绑定；
  在大量同人动画（经典 Null vs Herobrine 系列）中被设定为 Herobrine 的宿敌。
  —— 模组还原：AFK 凝视、世界篡改（方块替换成圆石 + 灰烬）、可参战。
- **实体 404**：中文社区"四大怪物"语境中的常客：错误代码 404 拟人化，
  绿色故障体，伴随错误文本刷屏与"游戏崩溃/断线"演出。
  —— 模组还原：闪烁瞬移逼近、错误文本刷屏、贴身"假断线"标题惊吓。

### 传说概况（2013 年前后出现）

- **起源叙事**：流传版本为——一名 **Mojang 员工（工号 303）被 Notch 开除**，其怨念化作
  游戏中的实体"Entity 303"，声称将在某个日期（常见说法为某年 5 月 31 日或"303 天后"）
  联合"黑客团队"**删除所有 Minecraft 世界**。与 Herobrine 一样，事后被认定为编造的
  creepypasta（2013–2014 年经由 YouTube 与各类"目击视频"传播，热度仅次于 Herobrine，
  但从未达到同等地位 —— Wikipedia 明确记载"类似的后续 creepypasta（如 Entity 303）
  再未匹敌 Herobrine 的声名"）。
- **形象**：**苍白脸孔 + 黑色兜帽/黑衣 + 发光的红色眼睛**（与 Herobrine 的"Steve 外形 +
  纯白眼睛"形成最鲜明的镜像对照）；数值梗 **"3:03 AM"**、303 号工牌。
- **行为**：与"只凝视、不伤人"的 Herobrine 相反，303 在传说中**真实具有恶意**：
  破坏世界、删除存档、纵火、伴随红色闪电现身。
- **敌对关系（同人主流设定）**：大量社区动画/同人作品（如经典的 "ENTITY 303 vs
  HEROBRINE" 系列动画、Monster School 等）将两者设定为**宿敌**：303 侵入世界报复，
  而 Herobrine 作为"旧日之主"与其开战 —— **白眼 vs 红眼** 的对决是社区文化中的名场面。

### 模组中的 303 与双雄之战

| 传说元素 | 模组实现（`him`） |
| --- | --- |
| 苍白脸 + 黑兜帽 + 红眼 | `Entity303Entity` + 自绘皮肤 + 红色发光眼层 |
| 恶意实体（与 Herobrine 相反） | `MODE_STALK`：主动追猎玩家，灼烧之爪（5 伤害 + 点燃 + 短暂黑暗） |
| 红色闪电 | 视觉闪电（`setVisualOnly`，不点燃世界）随现身/退场与技能劈落 |
| 303 vs Herobrine 宿敌对决 | `BattleManager`：双方 120/130 点"幻影血量"真实互殴 —— Herobrine 挥剑（9/击）+ 念力冲击波（6/击 + 击退），303 火焰爪（8/击）+ 红雷（14/击） |
| 战斗演出 | 开战闪电 + 守卫者诅咒低鸣；战场周期雷声与随机落雷；败者湮灭（303 化烈焰 / Herobrine 化黑烟电花），胜者凝视"观众"数秒后离去；90 秒不分胜负则双双退场 |
| 神之战不可干预 | 双方本体无敌，玩家只能围观（战局由幻影血量结算） |
| 触发节奏 | 目击 Herobrine ≥3 次后，闹鬼事件中约 8% 触发大战；303 单独追猎约 6%（潜伏期 2%） |


## 9. Herobrine 传说 → 模组 映射表

| 传说元素 | 模组实现（`him`） |
| --- | --- |
| 白眼、玩家外形、沉默 | `HerobrineEntity` + 自绘 64x64 皮肤 + `EyesLayer` 全亮发光眼 |
| 雾中远距离凝视 | `trySighting(MODE_STARE)`：视线方向 ±34°、22–48 格、面朝玩家站定 |
| 被注视数秒即消失 | `trackActive()`：注视判定 `dot > 0.982` 约 2.25 秒后化作黑烟消失 |
| 靠近即消失 | 距离 < 14 格：黑烟 + 灵魂粒子消失 |
| "一回头就不在了" | 玩家视线离开 7 秒 → **无声**消失 |
| 从不主动攻击 | 静默实体（无环境音/受伤音），不可被杀死（`setInvulnerable`） |
| 直播被切断的名场面 | 深夜逼近事件（`MODE_APPROACH`）：贴身 → 黑暗+失明+雷声（`harmlessMode` 可关伤害） |
| 岩浆上行走（Patimuss） | 实体 `fireImmune()` |
| 2x2 隧道 + 红石火把 | `carveTunnel()`：山体直线 2x2、红石火把、35% 概率他在尽头等你 |
| 被扒光树叶的树 | `stripTrees()`：移除树干周围树叶、保留原木 |
| 水中沙金字塔 | `buildPyramid()`：3x3 + 十字 + 顶心，共三级 |
| 燃烧的下界岩 | `lightFire()` |
| 告示牌 "ONLY GOD CAN HELP YOU NOW" 等 | `placeSign()`：`WAKE UP`（him.html）/`STOP`（私信）/ 上句（伪造截图），打蜡不可改 |
| 火把异变 | `swapTorch()`：把你家的火把换成红石火把 |
| 诡异音效 | `ambientDread()`：末影人凝视 / 传送门 / 监守者心跳（均为原版音效，还原"13 号唱片+洞穴音"氛围） |
| 金块图腾召唤 | `TotemHandler`：2 金块 + 下界岩 + 4 红石火把，点燃 → 进入 stage 1 |
| "Removed Herobrine" | 模组加载日志：`LOGGER.info("Removed Herobrine.")` |
| 主世界传说 | 所有事件仅发生在主世界（Overworld） |
